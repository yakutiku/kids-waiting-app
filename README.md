# あそぼう(5さい向け 待ち時間アプリ)

家族の個人利用のためのウェブアプリ(PWA)。iPhone(Safari)と Fire タブレット(Silk)向け。
外部と通信せず、広告・課金・点数・タイマーはありません。音は初期設定でオフです。

## おとなの せってい
ホーム右上の歯車を **3秒ながおし**。音・読み上げ・ことば(にほんご/えいごも/English)・ころころそうち「リアルなうごき」(Matter.js 版)・記録の消去。

## 開発
- ビルド不要。`node tools/serve.js 8080` → http://localhost:8080/
- ファイルを変えたら `node tools/build-sw.js`(オフライン用ファイル一覧の更新)
- 確認: `node tests/check.js`(サーバー 8090 起動中)、`node tests/korokoro-sim.mjs`、`node src/genres/senro/test.mjs`
- ジャンルの作り方: docs/GENRE_API.md
- 同梱ライブラリ: src/vendor/matter-0.20.0.min.js(MIT、src/vendor/matter-LICENSE.txt)。「リアルなうごき」をオンにしたときだけ読み込む。
